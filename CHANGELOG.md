# Değişiklik günlüğü / Changelog

## [1.0.0] - 2026-11-23

### Eklendi / Added

- Kategoriler, ürünler, boy seçenekleri (en çok 3 fiyat), etiketler, eski fiyat ve tükendi durumu
  / Categories, products, size options (up to 3 prices), labels, old price and sold-out state
- Toplu fiyat güncelleme: yüzde veya tutar, yuvarlama, uygulamadan önce önizleme
  / Bulk price update: percent or amount, rounding, preview before applying
- Gün, saat ve tarih aralıklı kampanya slaytları
  / Promotion slides with day, hour and date ranges
- Çoklu ekran: menü + kampanya, yalnız menü, yalnız kampanya
  / Multiple screens: menu + promotions, menu only, promotions only
- Otomatik sütun, ölçek ve sayfalama; 3 tema; yatay ve dikey ekran
  / Automatic columns, scaling and paging; 3 themes; landscape and portrait
- Güvenli görsel yükleme, logo, örnek menü
  / Safe image uploads, logo, sample menu
- SQLite ve MySQL, kurulum sihirbazı, Türkçe ve İngilizce panel
  / SQLite and MySQL, setup wizard, Turkish and English panel
